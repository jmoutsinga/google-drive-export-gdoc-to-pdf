# google-drive-export-gdoc-to-pdf

A google drive workspace extension for google docs that add in the Extension menu a new item "Export current gDoc to pdf". 
This pdf file is created in the same google drive folder of the gdoc

Export current gDoc to PDF saves a PDF copy of the open document in its Google Drive folder.

How to use:

1. Open your Google Docs document.
2. Select Extensions → Export current doc => PDF (same dir) → Créer le PDF maintenant.
3. Find the newly created PDF version of your doc in the same folder as the original document.

The PDF uses the document’s name. Each export creates a new file; existing PDFs are preserved.

You must have permission to read the document and create a file in its folder.
