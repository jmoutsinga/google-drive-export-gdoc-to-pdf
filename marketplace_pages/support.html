Créer votre PDF

  1. Ouvrez le document Google Docs et attendez la fin de son enregistrement.
  2. Dans Extensions, ouvrez le menu du module d’export PDF et sélectionnez l’action de création du PDF.
  3. Accordez les autorisations Google si elles sont demandées.
  4. Retrouvez le PDF dans le dossier du document. Chaque lancement crée une nouvelle copie.

Résoudre un problème

  • Menu absent : vérifiez que le module est installé avec le compte actuellement connecté et rechargez le document. Un déploiement de test s’applique aux documents sélectionnés pour ce test.
  • Accès refusé : vérifiez vos droits sur le document et votre droit de création dans son dossier.
  • PDF introuvable : ouvrez le dossier du document et triez les fichiers par date de modification.
  • Erreur temporaire ou quota : attendez avant de réessayer et évitez les clics répétés.

Contacter le développeur

Signalez un problème via GitHub Issues. Indiquez les étapes suivies, le résultat attendu et le message d’erreur, après avoir masqué toute donnée personnelle. Les tickets peuvent être publics : n’y joignez pas vos documents confidentiels ni vos identifiants. Les réponses dépendent de la disponibilité du développeur ; aucun délai de réponse n’est garanti.

Retirer les autorisations

Utilisez les connexions de votre compte Google pour révoquer l’accès. La révocation ne supprime pas les PDF déjà créés.

Create your PDF

  1. Open the Google Docs document and wait for it to finish saving.
  2. Under Extensions, open the PDF export add-on’s menu and select its PDF creation action.
  3. Grant the Google permissions if prompted.
  4. Find the PDF in the document’s folder. Each run creates a new copy.

Troubleshooting

  • Missing menu: check that the add-on is installed for the account currently signed in and reload the document. A test deployment applies to its selected test documents.
  • Access denied: check your access to the document and your permission to create files in its folder.
  • Cannot find the PDF: open the document’s folder and sort files by modification date.
  • Temporary error or quota: wait before retrying and avoid repeated clicks.

Contact the developer

Report problems through GitHub Issues. Include the steps taken, expected result and error message after removing personal data. Issues may be public: do not attach confidential documents or credentials. Replies depend on developer availability; no response time is guaranteed.

Revoke permissions

Use Google Account connections to revoke access. Revoking access does not delete PDFs already created.
