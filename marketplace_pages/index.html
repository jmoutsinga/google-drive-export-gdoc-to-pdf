Votre document, en PDF, dans le même dossier

Export PDF crée une copie PDF du document Google Docs ouvert dans son dossier Google Drive. Le fichier reprend le nom du document. Chaque export crée un nouveau fichier et conserve les PDF existants.

Retrouvez les instructions sur la page d’assistance, les conditions d’utilisation et la politique de confidentialité.

Your document, as a PDF, in the same folder

Export PDF creates a PDF copy of the open Google Docs document in its Google Drive folder. The PDF uses the document’s name. Each export creates a new file and preserves existing PDFs.

Read the support guide, terms of use and privacy policy.
