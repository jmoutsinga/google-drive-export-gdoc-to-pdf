Politique de confidentialité

Export current gDoc to PDF est développé par Julien Moutsinga. Cette politique décrit le traitement des données lors de l’export d’un document. Contact : GitHub Issues.

Données utilisées et finalité

À votre demande, le module accède au document ouvert, à son identifiant, à son nom et à son contenu pour le convertir en PDF. Il utilise les informations de son dossier parent pour y enregistrer le fichier créé. Le traitement s’effectue dans les services Google Apps Script, Google Docs et Google Drive.

Autorisations Google

documents.currentonly permet d’accéder au document ouvert. L’autorisation drive accorde techniquement un accès étendu aux fichiers Drive ; le module l’utilise pour retrouver le dossier du document, convertir celui-ci et créer le PDF. Il ne parcourt pas les autres documents et ne les utilise pas à d’autres fins.

Partage et utilisation limitée

Le module n’envoie pas le contenu des documents à un serveur du développeur. Il ne vend pas les données, ne les utilise pas à des fins publicitaires et ne les utilise pas pour entraîner des modèles d’intelligence artificielle. Les données Google sont utilisées uniquement pour réaliser l’export demandé. L’utilisation et le transfert des informations reçues des API Google respectent la Google API Services User Data Policy, notamment ses exigences d’utilisation limitée (Limited Use).

Conservation et suppression

Le développeur ne constitue pas de base de données des documents ou des PDF. Les PDF restent dans votre Drive jusqu’à leur suppression par vous ou une personne autorisée. L’export ne déclenche aucun partage volontaire du PDF ; vérifiez les accès hérités du dossier de destination. Google peut conserver des données techniques d’exécution conformément aux paramètres et règles de ses services.

Vous pouvez révoquer l’accès dans les connexions de votre compte Google et désinstaller le module. Cela empêche les futurs accès autorisés mais ne supprime pas les PDF déjà créés.

Site et assistance

Ces pages n’intègrent ni outil d’analyse d’audience, ni publicité, ni cookie applicatif. L’hébergement GitHub Pages peut traiter des données techniques de connexion selon la politique de GitHub. Si vous ouvrez un ticket, les informations que vous publiez sont conservées par GitHub et peuvent être publiques. Ne transmettez pas de document confidentiel, de jeton ni de mot de passe.

Vos demandes et les changements

Pour toute question ou demande relative aux données que vous avez volontairement transmises au support, contactez le développeur via GitHub Issues, sans publier les données concernées. Toute modification de cette politique sera indiquée sur cette page avec sa date de mise à jour.

Privacy policy

Export current gDoc to PDF is developed by Julien Moutsinga. This policy describes data handling when exporting a document. Contact: GitHub Issues.

Data used and purpose

At your request, the add-on accesses the open document, its ID, name and content to convert it to PDF. It uses information about the parent folder to save the generated file there. Processing takes place within Google Apps Script, Google Docs and Google Drive.

Google permissions

documents.currentonly provides access to the open document. The drive permission technically grants broad access to Drive files; the add-on uses it to locate the document’s folder, convert the document and create the PDF. It does not browse other documents or use them for other purposes.

Sharing and Limited Use

The add-on does not send document content to a developer-operated server. It does not sell data, use it for advertising or use it to train artificial intelligence models. Google data is used only to perform the requested export. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The developer does not maintain a database of documents or PDFs. PDFs remain in your Drive until deleted by you or an authorized person. Exporting does not deliberately share the PDF; check permissions inherited from the destination folder. Google may retain technical execution data under its service settings and policies.

You can revoke access through Google Account connections and uninstall the add-on. This prevents future authorized access but does not delete previously created PDFs.

Website and support

These pages include no analytics, advertising or application cookies. GitHub Pages hosting may process technical connection data under GitHub’s privacy statement. Information you submit in an issue is retained by GitHub and may be public. Do not submit confidential documents, tokens or passwords.

Requests and changes

For questions or requests about information you voluntarily provided to support, contact the developer through GitHub Issues without posting the affected data. Changes to this policy will be reflected on this page with an updated date.
